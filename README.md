# 九九九九乘法表

[进入好友小站](https://yanovo-jiujiu.noisy-pear-6946.chatgpt.site) · [打开本机体验版](https://yanovoovo-source.github.io/9999/)

本机体验版支持手机与电脑角色库、分页搜索与收藏、角色创作、XML/JSON导入、独立整页剧情聊天，以及类似即时消息的小手机聊天、通讯录、最近消息和表情。剧情与小手机沿用同一角色的对话和记忆；背景、主题、气泡、字体与自定义CSS可分别美化，并可保存角色专属样式。

个人API直接连接服务商；密钥只在页面内存中，刷新清除，服务商需要支持浏览器跨域(CORS)。已保存的角色与对话保存在当前浏览器，可导出角色和聊天JSON备份。未发送草稿和保存失败的临时对话可在同账号本次页面切换中保留，刷新或关闭页面仍可能丢失，请及时备份。

好友小站另支持邀请码注册、昵称密码登录、私有/好友角色权限，以及账号独立的云端对话保存和确认恢复。GitHub Pages本身不提供账号和数据库，请从好友与账号页面进入好友小站。

复杂旧站组件与加密美化仍需继续适配。此仓库仅保存公开网页构建文件；完整源码在作者的私有仓库，不包含私人角色素材或密钥。
